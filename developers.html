Advisory contract

The backend source accepts bounded advisory evaluation requests and reports outcomes as advisory results. A result is not a workload control, a security authorization, or a claim of active protection. Do not send credentials, secrets, personal data, or sensitive system details to an unverified endpoint.

Before using an API key

  • Wait for a verified account and entitlement workflow.
  • Keep customer API keys in a server-side secret manager; never embed them in browser JavaScript.
  • Do not use the API for enforcement, shutdown, or safety certification.
  • Confirm the published base URL, auth scheme, request schema, rate limits, retention, and support path before integration.
